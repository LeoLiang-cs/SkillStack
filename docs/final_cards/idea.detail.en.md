# Boundary Load Maps: Testing Declared Skill Interfaces by Differentiated Atom Restoration

**Method.** Boundary Load Mapping (BLM)

## Motivation
**Problem framing.** Modular LLM-agent research has adopted a working method that quietly conditions away the quantity it claims to measure. The Phase 1 bottleneck statement names it directly: any evaluation that declares an interface before transplanting heterogeneous implementations risks absorbing the incompatibilities it set out to detect, because nominally matching components can depend on different latent state, applicability, evidence, failure, and update semantics. The problem class is therefore the schema-first transplant — modular evaluations in which a boundary is authored before measurement, so that a changed outcome after a swap cannot be attributed to intrinsic implementation quality, receiver-stack compatibility, or neighboring-module interaction.

Each of the closest adjacent papers instantiates this pattern. AgentSquare (arxiv:2410.06153v3) makes recombination executable only by fitting planning, reasoning, tool-use, and memory modules into one uniform four-part boundary before searching 1,050 recombinations; SkCC (arxiv:2605.03353v4) certifies cross-framework portability after lowering a skill into a typed IR whose semantic completeness is never tested against receiver behavior; GraSP (arxiv:2604.17870v1) permits substitution inside a precondition-effect DAG while trusting those declared contracts to capture the downstream requirements that matter; and SkillAlign (arxiv:2609.07255v1) varies exposure form while holding the implementation axis fixed, so cross-pairing dependencies never enter its design. In none of these systems is there a measurement that shows which undeclared dependencies a receiver actually consumes and which of them carry the outcome.

This work takes the anchor setting as the primary instance of the class: GRASP-proposer and SkillRL-updater components are transplanted into a non-native SkillStack receiver on two frozen ALFWorld manifests, with the declared schema fixed at `docs/canonical_interface_v1.md`. Rather than normalizing semantics into a uniform boundary, the method measures the boundary that already exists — censusing every atom the receiver consumes at its read points, then restoring atoms one at a time and scoring the effect against the environment oracle. The question is no longer whether a swap works, but whether declared interface coverage — not behavior — is the load-bearing axis of portability, and the answer becomes a falsifiable completeness certificate per declared boundary.

**Why now.** Every adjacent line of work from the last year has converged on declared boundaries without closing them: SkCC (arxiv:2605.03353v4) certifies portability after compilation into a typed IR, GraSP (arxiv:2604.17870v1) gates substitution on declared precondition-effect coverage, and SkillAlign (arxiv:2609.07255v1) fixes the implementation and varies only the exposure form, while Interface-Induced Trajectory Censoring (arxiv:2609.03966v1) documents that frozen-seed interface swaps alone can collapse success from 0.96 to 0.00 with the effect living in a template $\times $ parser interaction. What makes the gap solvable now is the combination none of them assembled: an evaluand-independent environment oracle (ALFWorld's goal predicate), saved-state replay with temperature-0 decoding that makes per-atom interventions exactly reproducible, and the SkillStack JSONL tracer plus typed registry that together let canonical alternatives be constructed per channel. The missing instrument — an oracle-scored per-atom presence probe — is now buildable from these three pieces.

**Why prior work stopped.**
- `arxiv:2410.06153v3` (arXiv 2024): AgentSquare standardizes planning, reasoning, tool-use, and memory modules to a uniform four-part IO interface and searches 1,050 recombinations inside one fixed agent workflow.
  - _Did not do_: It never measures which paper-native semantics were discarded during admission or whether an implementation's ranking survives a receiver with different state and control contracts.
  - _Structural reason_: Its search objective is recombination ranking inside a fixed abstraction, so it lacks the measurement primitive — an oracle-scored per-atom presence probe — that would expose dependencies the uniform boundary filtered out.
- `arxiv:2605.03353v4` (arXiv 2026-05): SkCC lowers a SKILL.md source into a typed SkIR, applies structural and security analyses, and emits framework-native renderings that certify portability after compilation.
  - _Did not do_: It does not test whether the typed representation retained every behaviorally load-bearing dependency of the original skill, so semantic loss that survives emission stays invisible.
  - _Structural reason_: Its certificate is defined on the compiled artifact rather than on measured receiver behavior, so it has no consumer-side outcome oracle against which to check the IR's completeness.
- `arxiv:2604.17870v1` (arXiv 2026): GraSP compiles skills into typed DAG nodes with preconditions, effects, and verifiers, and admits substitution only when declared effect coverage satisfies downstream requirements.
  - _Did not do_: It never tests the coverage assumption itself — no executed contrast shows that the declared contracts contain every dependency that determines downstream success.
  - _Structural reason_: It lacks the saved-state re-injection instrument that converts declared coverage from a substitution precondition into a falsifiable per-atom hypothesis.
- `arxiv:2609.07255v1` (arXiv 2026-09): SkillAlign fixes the task, backend, and candidate skills and varies only the exposure interface to measure its effect on utility and context cost.
  - _Did not do_: It never varies the underlying implementation or neighboring modules, so it cannot tell whether a measured gain travels across component pairings or is contingent on the native stack.
  - _Structural reason_: Its counterfactual design holds the transplantation axis constant by construction, leaving cross-pairing boundary dependencies outside its manipulated variables.

**What changes when the gap closes.** With a load map in hand, a paper reporting component rankings can state exactly which boundary atoms its gains depend on, turning unreported native pairings from a confound into a declared artifact. Substitution machinery like GraSP (arxiv:2604.17870v1) and compilation pipelines like SkCC (arxiv:2605.03353v4) gain a measurement target — oracle-certified load-bearing coverage — against which declared contracts and IR completeness can be checked rather than assumed. The field also gains a unit of comparison for cumulative modular progress: interchangeability claims become falsifiable per declared boundary instead of per whole system.

## Method
**Pipeline.** The method starts from a frozen cell manifest and an instrumented tracer that records every boundary atom a SkillStack receiver actually consumes. Native-reference and crossed cells for the GRASP and SkillRL A-slot variants run on one deterministic replay lattice to yield the swap delta `D(r,n)`. From each crossed-cell run's saved pre-consumption state, a side-car re-injects single recorded atoms — first their real native values, then canonical alternatives — and scores paired presence effects against ALFWorld's goal oracle, with per-stratum joint-mask arms localizing jointly-required load. An inert carrier and full native-payload restoration bound the map against carrier artifacts, and an exact accounting identity states how much of `D(r,n)` the certified load map explains. The output is a per-boundary completeness verdict against the declared schema plus a schema-later interface induced from the oracle-certified load-bearing strata.

### M1_background
*Frozen measurement basis the probes attach to: immutable cell manifest and declared-schema baseline, boundary-atom census instrumentation, native and crossed cell runs on the deterministic replay lattice, and the typed registry of canonical alternatives.*

1. **Freeze the cell manifest and declared-schema baseline** (`S1`)
   - Freeze the full cell population into one immutable manifest: the two task manifests `configs/p0_tasks_picktwo9.json` and `configs/p0_tasks_hard.json` (copied byte-for-byte), the preregistered seed list (one integer per line, fixed before any run), the GRASP-proposer and SkillRL-updater A-slot source commits (exact commit SHAs, each with a fidelity tag `faithful` or `adapted` recording whether the pinned commit matches the paper's released implementation), the receiver and neighbor settings, prompts, budgets, and a machine-readable declared-atom table compiled once from `docs/canonical_interface_v1.md` (every declared (channel, key) pair with its declared domain where stated). The manifest is a JSON file with canonically sorted entries and a SHA-256 hash of its canonical serialization recorded inside it; any change to any frozen object breaks the hash and invalidates downstream results. This one object defines the frozen population U and the declared-schema baseline that every S7 declaredness judgment is made against.
   - _Why:_ Every downstream effect is exact only on a frozen finite population, so declaredness judgments and the swap delta need one fixed reference object.
2. **Instrument the tracer to emit the boundary atom census** (`S2`)
   - Extend `src/skillstack/tracing/jsonl.py` so that every consumption event at an explicit adapter consumer point emits one atom into an append-only census. Each atom is one JSON line with the fixed schema $\{atom_{id}$ (monotonically increasing), $run_{id}, cell_{id}, task_{id}$, seed, episode_step, consumer_point_id (the file:function site), channel, key, recorded_native_value (the producer's value exactly as delivered at that read, serialized together with its runtime type tag), read_locus (consumer_point_id + event class + the per-key occurrence ordinal, so the side-car can re-target this exact read), event_class $\in $ {raw_read, default, drop, rejection, no-op, fallback, version}}. The census file is opened in append mode once per execution, one line per event, flushed on every event, and hashed at run end; lines are never rewritten. Emission happens at the consumer point itself, before any value transformation, so the census is what the receiver actually consumed, not what the producer declared.
   - _Why:_ The load map is defined on what the receiver actually consumes, not what the producer declares, so the census replaces schema-trust with observed consumption.
3. **Run native and crossed cells on one deterministic replay lattice** (`S3`)
   - Execute the frozen cell grid. A cell is the tuple (A-slot variant, receiver, neighbor, task, seed); each variant runs once natively — in its own stack's receiver — and once crossed — identical receiver, neighbor, task, and seed, adapter untouched, with only the A-slot source code swapped for the other variant's commit — yielding 2 native and 2 crossed cells per (neighbor, task, seed). Every cell decodes with temperature 0 (greedy: always the single most likely next token) and all random-number-generator seeds frozen; the replay lattice is the per-cell Cartesian product of manifest seeds $\times  R_{rep} = 8$ replays, each replay restarting from the same saved initial state. Save per-replay traces, episode completion states, and ALFWorld's binary goal predicate outcome; the per-seed goal success is the mean of the seed's 8 binary goal indicators. The swap delta for each (receiver, neighbor) cell is computed as the seed-mean of the paired difference — per-seed goal success in the native cell minus the same in the crossed cell — paired per seed on the same replay lattice, so a positive value means the crossing lost goal success. Every cell runs the S2 tracer, so native and crossed runs both carry per-atom consumption records.
   - _Why:_ Putting the swap delta and every per-atom effect on the same replay lattice keeps them comparable instead of confounded by decoding noise.
4. **Build the typed intervention registry of canonical alternatives** (`S4`)
   - Build the intervention registry keyed by (channel, key). For each channel, enumerate canonical alternative values z from three sources: (1) the Boolean complement — the logical negation of the recorded value, admitted only if the channel's existing parser accepts the negated literal; (2) declared enum members — every value the S1 declared-atom table lists for the channel's key; (3) same-role object symbols — other instances of the same ALFWorld object type present in that seed's saved state (e.g., other receptacles of the same class). Every candidate passes through the channel's existing parser and admission path at the consumer point; a candidate is admitted iff it parses without error and passes the channel's type/domain check, and is written to the rejected-alternative log with the reason otherwise. The registry stores per (channel, key): the admitted-alternative list in canonical order, the rejected log, and a fail-closed flag set iff the channel's domain is numeric, a continuous schema range, or a singleton, or the admitted list is empty. The registry is a canonically sorted JSON file, hashed, and frozen before any S6 probe.
   - _Why:_ Content claims require a constructible alternative value; the fail-closed marking keeps the certificate honest on numeric, schema-range, and singleton channels where no canonical contrast exists.

### M2_probe
*The presence probe: score each atom's paired presence effect by re-injecting its real recorded value at its read locus, then disambiguate presence from content with canonical alternatives.*

5. **Probe per-atom presence with real recorded values** (`S5`)
   - For every atom consumed in a crossed-cell run, take the saved pre-consumption ALFWorld state — the serialized environment checkpoint plus the receiver's resumable execution context captured at the consumption hook, which S2's instrumentation turns into a resumable boundary. The probe population is the atoms the crossed run consumed: cross-absent atoms (present only in the native census, hence no crossed-run read locus) are excluded, and atoms whose (channel, key) never appears in the matched native census have no native value to restore and are excluded as censored. For a probed atom, the native value v* is the matched native run's recorded value for the same (channel, key), paired by consumption order (k-th occurrence against k-th); atoms whose crossed value already equals v* are value-identical and presence-inert by construction (no arms run, effect recorded as exactly zero). For each remaining atom, the side-car restores the checkpoint and resumes the receiver at the recorded read/default/drop locus with v* force-fed through the normal accepted-value path (restored arm); the un-restored arm resumes from the same checkpoint with no injection. 【author decision: the S2 census also records rejection, no-op, fallback, and version events, but this step names only read/default/drop loci — decide whether those four event classes are probed with the same force-feed semantics, or marked censored for the S7 joint masks and the S10 abstention rule; the choice fixes the probe population and the certificate's coverage.】 Both arms replay $R_{rep} = 8$ times per seed — the seed set S is the manifest seeds in which the crossed run consumed the atom — under temperature-0 decoding with frozen RNG, and the per-seed goal success is the mean of the 8 binary goal indicators from ALFWorld's goal predicate. Score the paired presence effect $\Delta _{a}$ as the seed-mean of goal_success(restored) minus goal_success(un-restored), preserving the sign.

*Per-atom presence effect: the mean over the seed set of the paired difference in ALFWorld goal success between the restored and un-restored arms replayed from the same saved pre-consumption state.*
$$ \Delta_a = \frac{1}{|S|} \sum_{s \in S} \left( G_s^{+} - G_s^{-} \right) \tag{1} $$

   - _Why:_ This is the missing measurement primitive the gap names: it converts declared coverage from an assumption into a per-atom falsifiable hypothesis without rewriting producer or neighbor code.
6. **Disambiguate presence from content with canonical alternatives** (`S6`)
   - For every atom in a canonical-content stratum — one whose (channel, key) has a non-empty admitted-alternative list in the S4 registry — inject each admitted alternative z through the unchanged parser at the same locus and from the same saved pre-consumption state used in S5, replaying the same $R_{rep} = 8$ lattice, and score $\Delta _{a}(z)$ with the same paired functional (seed-mean of goal_success(z-arm) minus goal_success(un-restored)). On the deterministic replay lattice the comparison is exact, with no statistical test: the atom is content-sensitive iff some admitted z gives an effect differing from $\Delta _{a}(v*)$; presence-sensitive iff every admitted z gives exactly $\Delta _{a}(v*)$ and that effect differs from zero; if every effect — $\Delta _{a}(v*)$ and all $\Delta _{a}(z)$ — is exactly zero, or the channel is fail-closed with no admitted z, emit an abstention record instead of a classification. Store per atom: classification $\in $ {content-sensitive, presence-sensitive, abstained}, the measured effect values, and the abstention reason.
   - _Why:_ Joint dependence can make both arms zero, so a forced classification would mislabel dependence as inertness; the abstention record preserves the certificate's fail-closed discipline.

### M3_loadmap
*The load map: aggregate the declaredness-partitioned per-atom and per-stratum joint-mask effects into the load map, then close the per-cell accounting identity.*

7. **Aggregate the declaredness-partitioned load map with joint masks** (`S7`)
   - Partition every census atom by declaredness — declared iff its (channel, key) appears in the S1 declared-atom table, undeclared otherwise — and by channel domain from the S4 registry (Boolean, enum, object-symbol, numeric, schema-range, singleton, event classes). Mark an atom load-bearing iff its $\Delta _{a}$ differs from exactly zero or S6 classified it content-sensitive. For every stratum whose probed atoms all have exactly-zero per-atom effects while the cell's swap delta differs from zero, run the per-stratum joint-mask arm: from each saved pre-consumption state, restore simultaneously through one carrier all value-differing atoms of the stratum within the S5 probe population — every stratum atom with a crossed-run locus whose crossed value differs from its paired native value — replay $R_{rep} = 8$ times per seed on the same lattice, and score the joint effect $J_{j}$ as the seed-mean of goal_success(joint-mask arm) minus goal_success(un-restored); strata with no probeable atoms are recorded joint-unprobeable and skip the arm. The certified undeclared load-bearing set is the union of undeclared atoms with $\Delta _{a} ≠ 0$ or content-sensitive, and undeclared strata with $J_{j} ≠$ 0.

*Per-stratum joint-mask effect: the mean over seeds of the paired difference in goal success between jointly restoring all value-differing atoms of one stratum through a single carrier and the un-restored arm.*
$$ J_j = \frac{1}{|S|} \sum_{s \in S} \left( G_s^{j+} - G_s^{-} \right) \tag{2} $$

   - _Why:_ Jointly-required load can be invisible to per-atom probes, so per-stratum joint masks localize the joint remainder without an exhaustive subset search over co-dependent atom groups.
8. **Close the per-cell accounting identity** (`S8`)
   - Close the per-cell accounting identity `D(r,n)` $= \Sigma $ over certified load-bearing atoms of $\Delta _{a} + \Sigma $ over certified joint-load-bearing strata of $J_{j} + \epsilon (r,n)$. Here `D(r,n)` is the cell's swap delta from S3 (the seed-mean of native minus crossed per-seed goal success), and the two certified sums are disjoint by construction — a joint arm runs only in strata whose per-atom effects are all exactly zero — so nothing is double-counted. Report per (receiver, neighbor) cell a table with: the swap delta, the certified per-atom sum, the certified joint sum, the remainder $\epsilon (r,n) =$ swap delta minus the two certified sums, the seed-basis count of each sum (each sum averages over the seeds on which its arms were defined), and the completion = certified sums divided by the swap delta, reported exactly as a fraction and marked undefined when the swap delta is zero. $\epsilon (r,n)$ stays unlabeled bookkeeping; it is labeled only in S10, and only when the joint coverage of the swap delta is certified there.

*Per-cell accounting identity: the swap delta decomposes into certified per-atom effects, certified joint-stratum effects, and a remainder $\epsilon (r,n)$ that stays unlabeled bookkeeping unless the joint coverage of the swap delta is certified.*
$$ D(r,n) = \sum_{a \in \mathcal{A}^{*}} \Delta_a + \sum_{j \in \mathcal{J}^{*}} J_j + \varepsilon(r,n) \tag{3} $$

   - _Why:_ The identity states exactly how much of the swap delta the certified map explains, so attribution claims never exceed the measured coverage.

### M4_validation
*Validation apparatus: inert-carrier and full-native-payload control arms, then the per-boundary completeness verdict and the induced schema-later interface.*

9. **Run the inert and full-payload control arms** (`S9`)
   - Run the two control arms for every cell. Negative control: take the measured-inert bulk — atoms whose probed per-atom effect is exactly zero (including both-arms-zero abstained atoms and fail-closed atoms with a zero effect) — and re-inject their recorded values through the same carrier mechanics at their own loci, replaying the same $R_{rep} = 8$ lattice; the carrier must not move success. Value-identical atoms stay out of the bulk: injecting their recorded value just re-runs the baseline and cannot exercise the carrier. Cells with an empty inert bulk record the negative control as not-run. Positive control: restore the full native payload — all value-differing atoms consumed in the crossed run, across all strata, injected simultaneously through one carrier — and compare its effect with the cell's swap delta; 'recover most of the swap delta' means the recovered share (full-payload effect divided by the swap delta) is strictly greater than half, and the exact share is always reported; a share at or below half fails the validity bound. Both control effects use the same paired functional (seed-mean of goal_success(control arm) minus goal_success(un-restored)).
   - _Why:_ The two controls separate genuine atom load from carrier artifacts and bound what any single stratum can explain.
10. **Emit the completeness verdict and the induced interface** (`S10`)
   - Issue the per-boundary verdict — one per declared boundary document, here `docs/canonical_interface_v1.md` — by a fixed decision procedure over the S7 certified undeclared load-bearing set and the S8 tables. (1) falsified: the certified undeclared set is non-empty — some undeclared atom has a nonzero or content-sensitive effect, or some undeclared stratum has a nonzero joint effect. (2) abstained: the probe population is empty, or every undeclared stratum is censored (no v*, no crossed-run locus) or fail-closed (no admitted alternative), or the swap delta `D(r,n)` differs from zero while the full-joint coverage fails the S9 validity bound — any case the stated conditions do not resolve. (3) not-falsified: `D(r,n)` equals zero, or the full-joint arm — the S9 full-payload positive control — has certified coverage of `D(r,n)` (recovered share strictly greater than half) with no undeclared load; in the certified-coverage case the S8 remainder $\epsilon (r,n)$ is labeled as the certified residual. Emit the schema-later interface: the union of oracle-certified load-bearing strata (declared and undeclared atoms and strata with nonzero certified effects) as an interface document listing each atom's (channel, key), declaredness, effect, and classification, plus the per-cell coverage table and both control effects.
   - _Why:_ Converts the load map into the certificate the gap demands — a declared boundary judged against measured load rather than assumed coverage.
