# Boundary Load Maps: Testing Declared Skill Interfaces by Differentiated Atom Restoration

**Method.** Boundary Load Mapping (BLM)

## Motivation
Modular LLM (large language model) agent research has adopted a working habit that quietly conditions away the quantity it claims to measure. Any evaluation that declares an interface before transplanting heterogeneous implementations risks absorbing the incompatibilities it set out to detect, because components that look interchangeable can still depend on different latent state, applicability, evidence, failure, and update semantics. The problem this work targets is the schema-first transplant: a modular evaluation in which the boundary is authored before measurement, so a changed outcome after a swap cannot be attributed to intrinsic implementation quality, receiver-stack compatibility, or neighboring-module interaction.

Each of the closest related systems instantiates this pattern. AgentSquare (arxiv:2410.06153v3) makes recombination executable only by fitting planning, reasoning, tool-use, and memory modules into one uniform four-part boundary before searching 1,050 recombinations. SkCC (arxiv:2605.03353v4) certifies cross-framework portability after lowering a skill into a typed IR (intermediate representation) whose semantic completeness is never tested against receiver behavior. GraSP (arxiv:2604.17870v1) permits substitution inside a precondition-effect DAG (directed acyclic graph) while trusting those declared contracts to capture the downstream requirements that matter. SkillAlign (arxiv:2609.07255v1) varies the exposure form while holding the implementation axis fixed, so cross-pairing dependencies never enter its design. In none of these systems is there a measurement that shows which undeclared dependencies a receiver actually consumes, and which of them carry the outcome.

This work takes the anchor setting as the primary instance of the class: GRASP-proposer and SkillRL-updater components are transplanted into a non-native SkillStack receiver on two frozen ALFWorld task manifests, with the declared schema fixed at `docs/canonical_interface_v1.md`. Rather than normalizing semantics into a uniform boundary, the method measures the boundary that already exists — censusing every atom the receiver consumes at its read points, then restoring atoms one at a time and scoring the effect against the environment oracle. The question is no longer whether a swap works, but whether declared interface coverage — not behavior — is the load-bearing axis of portability, and the answer becomes a falsifiable completeness certificate per declared boundary.

What makes the gap solvable now is a combination no adjacent line has assembled: an environment oracle that does not depend on the evaluated system (ALFWorld's goal predicate), saved-state replay with temperature-0 decoding that makes per-atom interventions exactly reproducible, and the SkillStack JSONL (JSON Lines) tracer plus typed registry, which together let canonical alternatives be constructed per channel. The missing instrument — an oracle-scored per-atom presence probe — is now buildable from these three pieces.

Prior work stopped at declared boundaries without closing them: one system's search objective lives inside a fixed abstraction, another's certificate is defined on the compiled artifact rather than on measured receiver behavior, a third trusts declared contracts without testing them, and a fourth holds the transplantation axis constant by construction — none of them has the measurement primitive that would expose dependencies the declared boundary filtered out. When the gap closes, a paper reporting component rankings can state exactly which boundary atoms its gains depend on, turning unreported native pairings from a confound into a declared artifact; substitution machinery like GraSP and compilation pipelines like SkCC gain a measurement target — oracle-certified load-bearing coverage — against which declared contracts and IR completeness can be checked rather than assumed; and interchangeability claims become falsifiable per declared boundary instead of per whole system.

## Method
### M1_background
*Frozen measurement basis the probes attach to: immutable cell manifest and declared-schema baseline, boundary-atom census instrumentation, native and crossed cell runs on the deterministic replay lattice, and the typed registry of canonical alternatives.*

1. Lock everything the experiment depends on into a single frozen manifest file: the two task lists `configs/p0_tasks_picktwo9.json` and `configs/p0_tasks_hard.json`, the pre-agreed seed list (one integer per line, fixed before any run), the exact source-code commit identifiers of the GRASP proposer variant and the SkillRL updater variant (each labeled faithful or adapted depending on whether the pinned code matches what the papers released), the receiver and neighbor settings, the prompts, the budgets, and a machine-readable table of every channel and key the interface document `docs/canonical_interface_v1.md` officially declares. The manifest is a JSON (JavaScript Object Notation) file whose entries sit in a fixed order, with a SHA-256 hash (a standard cryptographic fingerprint) of its contents stored inside it; if anything is later changed, the hash stops matching and every downstream result is void. This one object defines the frozen population of runs and the official declared interface that later steps compare against.
   - _Why:_ Every downstream effect is exact only on a frozen finite population, so declaredness judgments and the swap delta need one fixed reference object.
2. Extend the tracing module `src/skillstack/tracing/jsonl.py` so that every time the receiving side consumes something at one of the adapter's explicit read points, one atom record is appended to a per-run census file. Each record is one line of JSON with a fixed set of fields: a running atom number, the run and cell identifiers, the task and seed, the episode step, the exact code location of the read, the channel and key being read, the value exactly as delivered (stored together with a tag saying its type), the read location including which read in the sequence this was (so a later replay can target this exact read), and the event class, which is one of exactly seven kinds: raw_read, default, drop, rejection, no-op, fallback, version. The file is append-only: lines are added one at a time and never edited, and a hash is taken when the run ends. Recording happens at the moment of consumption, before any conversion, so the census shows what the receiver actually consumed rather than what the producer claimed.
   - _Why:_ The load map is defined on what the receiver actually consumes, not what the producer declares, so the census replaces schema-trust with observed consumption.
3. Run the full grid of cells frozen in the manifest. A cell is one combination of: which A-slot variant is plugged in, which receiver is consuming it, the neighbor, the task, and the seed. Each variant runs once in its home stack (native cell) and once transplanted into the other stack's A-slot with the adapter left untouched (crossed cell); the receiver, neighbor, task, and seed are identical across the pair, so only the A-slot source code changes. Every cell decodes greedily — temperature 0, always picking the single most likely next token — with all random number generator (RNG) seeds frozen, and each seed is replayed 8 times $R_{rep} = 8$ from the same saved starting state; the goal success of a seed is the average of its 8 yes/no goal outcomes. Keep the full replay traces, the episode completion records, and ALFWorld's built-in yes/no goal check. The swap delta for each (receiver, neighbor) cell is the seed-by-seed average of (native cell success minus crossed cell success), so a positive number means the transplant lost goal success.
   - _Why:_ Putting the swap delta and every per-atom effect on the same replay lattice keeps them comparable instead of confounded by decoding noise.
4. For every channel, assemble the registry of alternative values z that can stand in for the recorded value. Take candidates from three places: the logical opposite (flip a true to false and vice versa), but only if the channel's existing parser accepts the flipped value; every value the official interface document declares for that channel's key; and, for object channels, other objects of the same kind that exist in the saved game state (for example, other bowls of the same type). Every candidate goes through the existing parser and the admission check the receiver already applies at that read point; a candidate is admitted only if it parses cleanly and passes the channel's type and range check, and any candidate that fails goes into the rejected log with the reason. For each (channel, key) the registry stores the admitted list in a fixed order, the rejected log, and a fail-closed flag, set when the channel's values are numeric, cover a continuous range, or allow only one value, or when no candidate is admitted. The registry is written as a JSON file, sorted, hashed, and frozen before any probing begins.
   - _Why:_ Content claims require a constructible alternative value; the fail-closed marking keeps the certificate honest on numeric, schema-range, and singleton channels where no canonical contrast exists.

### M2_probe
*The presence probe: score each atom's paired presence effect by re-injecting its real recorded value at its read locus, then disambiguate presence from content with canonical alternatives.*

5. For every atom the crossed run consumed, start from its saved pre-consumption game state — a snapshot of the ALFWorld environment plus the receiver's paused execution context taken just before that read, which the step 2 (Extend the tracing module...) instrumentation turned into a resumable point. The atoms the crossed run consumed form the probe population: atoms present only in the native run's records have no read point inside the crossed replay, so they are excluded; atoms whose (channel, key) never appears in the matched native run's records have no native value to restore, so they are excluded as censored. For a probed atom, the native value v* is the value the matched native run recorded for the same (channel, key), paired read-for-read in the order they happened; if the crossed run already consumed exactly v*, the atom is value-identical and inert by construction — no replay is needed and its effect is recorded as exactly zero. For every remaining atom, the side-car restores the snapshot and resumes the receiver at the recorded read/default/drop point with v* fed in through the normal accepted-value path (restored arm); the un-restored arm resumes from the same snapshot with nothing injected. 【author decision: the step 2 (Extend the tracing module...) census also records rejection, no-op, fallback, and version events, but this step names only read/default/drop points — decide whether those four event kinds are probed the same way, or marked censored for the step 7 (Sort every atom into groups by two...) joint masks and the step 10 (Give one verdict per declared...) abstention rule; the choice decides which atoms can be probed and how much of the boundary the certificate covers.】 Both arms replay 8 times per seed $R_{rep} = 8$ — over the seeds in which the crossed run consumed the atom — with temperature 0 and frozen RNG; the per-seed goal success is the average of the 8 yes/no goal outcomes from ALFWorld's goal check. The paired presence effect $\Delta _{a}$ is the seed-by-seed average of goal_success(restored) minus goal_success(un-restored), keeping the sign.

*Per-atom presence effect: the mean over the seed set of the paired difference in ALFWorld goal success between the restored and un-restored arms replayed from the same saved pre-consumption state.*
$$ \Delta_a = \frac{1}{|S|} \sum_{s \in S} \left( G_s^{+} - G_s^{-} \right) \tag{1} $$

   - _Why:_ This is the missing measurement primitive the gap names: it converts declared coverage from an assumption into a per-atom falsifiable hypothesis without rewriting producer or neighbor code.
6. For every atom whose channel has at least one admitted alternative in the step 4 (For every channel) registry, take each admitted alternative z, inject it through the unchanged parser at the same read point and from the same saved pre-consumption state as in step 5 (For every atom the crossed run...), and replay the same 8-replay lattice; the z-effect is scored the same way — average over seeds of goal_success(z-arm) minus goal_success(un-restored). Because the replay lattice is deterministic, the comparison is exact and no statistical test is involved: the atom is content-sensitive if any admitted z gives an effect different from the v*-effect; presence-sensitive if every admitted z gives exactly the v*-effect and that effect is not zero; if all effects — the v*-effect and every z-effect — are exactly zero, or the channel is fail-closed with no admitted alternative, write an abstention record instead of a classification. Each atom is stored with its classification — content-sensitive, presence-sensitive, or abstained — the measured effect values, and the reason for abstention.
   - _Why:_ Joint dependence can make both arms zero, so a forced classification would mislabel dependence as inertness; the abstention record preserves the certificate's fail-closed discipline.

### M3_loadmap
*The load map: aggregate the declaredness-partitioned per-atom and per-stratum joint-mask effects into the load map, then close the per-cell accounting identity.*

7. Sort every atom into groups by two labels: declaredness — declared if its (channel, key) appears in the machine-readable table extracted from `docs/canonical_interface_v1.md` at the start, undeclared otherwise — and channel domain from the step 4 (For every channel) registry (Boolean, enum, object-symbol, numeric, schema-range, singleton, or the event classes). Mark an atom load-bearing if its per-atom effect differs from exactly zero or step 6 (For every atom whose channel has at...) classified it content-sensitive. Then, for every group whose probed atoms all have exactly-zero per-atom effects while the cell's swap delta differs from zero, run the joint-mask arm for that group: from each saved pre-consumption state, restore at the same time through one carrier all value-differing atoms of the group that step 5 (For every atom the crossed run...) could probe — every group atom with a read point in the crossed run whose crossed value differs from its paired native value — replay 8 times per seed $R_{rep} = 8$ on the same lattice, and score the joint effect $J_{j}$ as the seed average of goal_success(joint-mask arm) minus goal_success(un-restored); groups with no probeable atoms are recorded as joint-unprobeable and skip the arm. The certified undeclared load-bearing set is the union of undeclared atoms with a nonzero effect or a content-sensitive classification, and undeclared groups with a nonzero joint effect.

*Per-stratum joint-mask effect: the mean over seeds of the paired difference in goal success between jointly restoring all value-differing atoms of one stratum through a single carrier and the un-restored arm.*
$$ J_j = \frac{1}{|S|} \sum_{s \in S} \left( G_s^{j+} - G_s^{-} \right) \tag{2} $$

   - _Why:_ Jointly-required load can be invisible to per-atom probes, so per-stratum joint masks localize the joint remainder without an exhaustive subset search over co-dependent atom groups.
8. Write the per-cell accounting table that closes the books: the swap delta equals the sum of the certified per-atom effects over all certified load-bearing atoms, plus the sum of the certified joint effects over all certified joint-load-bearing groups, plus a remainder. The two certified sums cannot overlap — a joint arm only runs in a group whose per-atom effects are all exactly zero — so nothing is counted twice. For each (receiver, neighbor) cell the table lists: the swap delta, the certified per-atom sum, the certified joint sum, the remainder (swap delta minus the two certified sums), how many seeds each sum was averaged over, and the completion — the certified sums divided by the swap delta, reported exactly as a fraction and marked undefined when the swap delta is zero. The remainder stays as unlabeled bookkeeping; it only gets a label in step 10 (Give one verdict per declared...), and only if step 10 (Give one verdict per declared...) certifies the joint coverage of the swap delta.

*Per-cell accounting identity: the swap delta decomposes into certified per-atom effects, certified joint-stratum effects, and a remainder $\epsilon (r,n)$ that stays unlabeled bookkeeping unless the joint coverage of the swap delta is certified.*
$$ D(r,n) = \sum_{a \in \mathcal{A}^{*}} \Delta_a + \sum_{j \in \mathcal{J}^{*}} J_j + \varepsilon(r,n) \tag{3} $$

   - _Why:_ The identity states exactly how much of the swap delta the certified map explains, so attribution claims never exceed the measured coverage.

### M4_validation
*Validation apparatus: inert-carrier and full-native-payload control arms, then the per-boundary completeness verdict and the induced schema-later interface.*

9. Run the two control arms for every cell. Negative control: collect the measured-inert bulk — atoms whose measured per-atom effect is exactly zero (including atoms that got a both-arms-zero abstention and fail-closed atoms with a zero effect) — and re-inject their recorded values through the same carrier machinery at their own read points on the same 8-replay lattice; the carrier itself must not move success. Value-identical atoms stay out of this bulk, because injecting their recorded value just reruns the baseline and cannot exercise the carrier. Cells with an empty inert bulk record the negative control as not-run. Positive control: restore the full native payload — every value-differing atom the crossed run consumed, across all groups, injected at once through one carrier — and compare its effect with the cell's swap delta; 'recover most of the swap delta' means the recovered share (full-payload effect divided by the swap delta) is strictly more than half, and the exact share is always reported; a share at or below half fails the validity bound. Both control effects use the same paired scoring: seed average of goal_success(control arm) minus goal_success(un-restored).
   - _Why:_ The two controls separate genuine atom load from carrier artifacts and bound what any single stratum can explain.
10. Give one verdict per declared boundary — here the single boundary in `docs/canonical_interface_v1.md` — using a fixed decision procedure over the certified undeclared load-bearing set and the accounting tables. First, falsified: the certified undeclared set is non-empty — some undeclared atom has a nonzero or content-sensitive effect, or some undeclared group has a nonzero joint effect. Second, abstained: the probe population is empty, or every undeclared group is censored (no native value, no crossed-run read point) or fail-closed (no admitted alternative), or the swap delta differs from zero while the full-joint coverage fails the step 9 (Run the two control arms for every...) validity bound — any case the stated conditions do not resolve. Third, not-falsified: the swap delta equals zero, or the full-joint arm — the step 9 (Run the two control arms for every...) full-payload positive control — has certified coverage of the swap delta (recovered share strictly more than half) with no undeclared load; when coverage is certified, the step 8 (Write the per-cell accounting table...) remainder gets labeled as the certified residual. Emit the schema-later interface: the union of oracle-certified load-bearing groups (declared and undeclared atoms and groups with nonzero certified effects) as an interface document listing each atom's (channel, key), declaredness, effect, and classification, plus the per-cell coverage table and both control effects.
   - _Why:_ This converts the load map into the certificate the gap demands — a declared boundary judged against measured load rather than assumed coverage.
