# Heat an object, then place it

**Task family:** `pick_heat_then_place_in_recep`

## Purpose

Heat one named object in a microwave before placing it at its destination.

## Procedure

1. Identify the object, microwave, and destination.
2. Locate and take the object, opening containers only as required.
3. Navigate to the microwave. Open it before inserting the object.
4. Put the object in the microwave, close the microwave, and invoke the
   environment's heating action.
5. Reopen the microwave, take the heated object, and place it at the requested
   destination.
6. Stop when task feedback indicates success.

## When to use

Use when the instruction says to heat, warm, or microwave an object before
placing it elsewhere.

## Common failure modes

- Heating is attempted while the object is not inside the microwave.
- The microwave is left open when the environment requires it to be closed.
- The agent forgets to retrieve the heated object after heating.
- The object is delivered to the destination before the heating step.
