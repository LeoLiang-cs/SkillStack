# Inspect an object with a desk lamp

**Task family:** `look_at_obj_in_light`

## Purpose

Make a named object observable under a named desk lamp.

## Procedure

1. Locate the requested object; open containers as needed to access it.
2. Take the object if the task requires it to be brought to the lamp.
3. Locate the desk lamp named or implied by the task.
4. Turn on the lamp.
5. Perform the environment action that examines the object with the active
   lamp, or check task feedback after the lamp/object condition is satisfied.

## When to use

Use for instructions involving looking at, examining, or inspecting an object
with a lamp. Do not use merely because a lamp happens to appear in the room.

## Common failure modes

- The lamp is found but remains off.
- The target object has not been retrieved from a container.
- The agent treats a visually related object as the requested one.
- The agent assumes that toggling the lamp alone completes the goal without
  confirming the object–lamp relation.
