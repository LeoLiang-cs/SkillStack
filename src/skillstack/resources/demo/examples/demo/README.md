# SkillStack zero-model demo fixture

This copy of the deterministic fixture is packaged with SkillStack so that the
`skillstack demo` command can run from an installed wheel or source archive,
without a checkout of the repository. It is the same public fixture as the
repository copy under `examples/demo/`.

The fixture validates the shared retrieval, adapter, execution, and tracing
path. It is not benchmark data and does not make a task-performance claim.
